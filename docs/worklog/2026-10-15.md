- Built `scripts/soak/rollback.sh` and `rollback.mjs`: private allowlisted current events PM2 capture, timestamped operator-owned `0600` records in `~/.imajin`, pinned standalone SHA, and read-only events migration hashes/names. No process environments, credentials, or raw subprocess output are persisted/reported.
- Rollback preflights the saved kernel definition, kernel `.next/BUILD_ID` (#2804 operator-build prerequisite), env-file permissions, tools, and migration compatibility before changing only events; then delete/start/save and timed loopback/public health (public URL comes from standalone env).
- Migration policy is strict: newly tracked hashes must exist among kernel checkout `migrations/*.sql` hashes; no baseline exception or force bypass. Approved baseline adoption must happen before recording, otherwise rollback refuses.
- Rehearsal is dev-only. Before cutover it records current kernel events; after cutover it must preserve/use an existing pre-cutover record, never record standalone as kernel. It preflights the pinned standalone deployment, rolls back, then deletes only events before `deploy.sh dev <recorded-SHA>` to avoid the stale-kernel refusal; successful completion leaves standalone.
- Failed rehearsal attempts recorded standalone recovery and still exits nonzero. Missing events after interrupted start is recoverable; failed recovery preserves the record and stops for private operator reconciliation. Tooling serializes per environment; a killed operator run can leave `~/.imajin/events-rollback-<env>.lock`, which needs private inspection before removal/retry.
