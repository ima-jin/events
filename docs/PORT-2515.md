# Events routes port (refs ima-jin/imajin-ai#2515)

Step 2 of the events rebuild (epic ima-jin/imajin-ai#1988): the routes, behaviour and api-spec of the kernel's
`apps/events`, running as a registered app with no kernel-internal imports.

## What is ported

- All 54 kernel `app/api/**/route.ts` handlers (route-for-route; `api-spec/openapi.yaml` documents each one, and
  `src/__tests__/api-spec.test.ts` fails CI if a route, method or `$ref` drifts from the spec).
- The kernel libraries under `src/lib`, including the #2734 ticket-holding statuses (`valid`, `sold`, `used`).
- The kernel's route and helper tests, rewritten against this app's seams (`@/lib/auth`, `@/lib/kernel`,
  `@/lib/domain-events`, `@/lib/surveys`), plus new tests for the api-spec and the `.fair` helpers.
- App-only additions: `/api/me`, `/api/auth/{callback,logout,session}` (SDK wrappers).

## Registered-app contract

- Auth: `requireSessionOrAppToken` (`@ima-jin/auth@^0.8.16`) behind `src/lib/auth.ts`. Tokens must be minted for
  audience `events` (registry slug, kernel #2706); scopes `events:read` (safe methods) / `events:write` are enforced on the
  token path; the session cookie is the migration fallback. Third-party `requireAppAuth` callers keep working on the
  routes that served them in the kernel.
- No `@imajin/*`, `workspace:*` or `apps/kernel` imports. Kernel data goes through `src/lib/kernel.ts`; surveys through
  dykil's public API (`src/lib/surveys.ts`).

## Not in this step

- UI pages (`app/**/page.tsx`, admin, checkout, create/edit) — the kernel's page tests (`event-edit-page`,
  `admin-page-attendees`, `guest-list-default-view`) are not ported with them.
- Closing the kernel gaps — see `docs/KERNEL-GAPS.md`.
